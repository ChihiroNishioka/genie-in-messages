# genie-in-messages 🧞

iMessageの中に常駐する、アンビエント型のアシスタントbot「ジーニー」（ランプの魔人🧞）。

ちひろ自身のApple IDから合図付きのメッセージを送ると、Mac mini上の常駐メニューバーアプリがそれを拾ってGrok Botに渡し、返事を同じトークにiMessageで返す。わざわざ別のアプリを開かなくても、いつものトークの中から呼び出せるのがコンセプト。

## ステータス

仕様書だけの段階。実装はまだない。

## ファイル

- [`SPEC.md`](SPEC.md): 仕様書（引き継ぎ用）。決定済み要件、アーキテクチャ、未決事項をまとめたもの。
- [`docs/design.md`](docs/design.md): 詳細設計案。初期の検討資料で、LaunchAgentとSwiftの小さなブリッジで🐦トークを中継する案として書かれている。現在の方針（メニューバーアプリ）は `SPEC.md` が正。
